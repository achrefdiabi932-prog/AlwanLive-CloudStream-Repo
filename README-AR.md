# مستودع Alwan Live لـ CloudStream / CSWeb TV

هذا مشروع إضافة Alwan Live. يحتوي المستودع على 16 قناة و33 رابط سيرفر في الملف `channels.json`. تقرأ الإضافة هذا الملف من فرع `main` عند فتح قائمة القنوات، لذلك يلزم اتصال إنترنت في التطبيق حتى تظهر القائمة.

## البناء والنشر

عند الدفع إلى `main` يبدأ GitHub Actions بمحاولة بناء الإضافة. إذا نجح البناء ينشر ملف `.cs3` وملفات الفهرس إلى الفرع `builds`.

رابط المستودع الذي يُضاف داخل CSWeb TV بعد نجاح البناء وظهور الملفات:

`https://raw.githubusercontent.com/achrefdiabi932-prog/AlwanLive-CloudStream-Repo/builds/repo.json`

لا تضف الرابط إلى CSWeb TV قبل نجاح GitHub Actions وظهور `repo.json` وملف الإضافة `.cs3` في الفرع `builds`.

## ملاحظات

- بيانات القنوات محفوظة في `channels.json` على فرع `main`، وليست مضمنة داخل ملف الإضافة في النسخة الحالية.
- روابط البث قد تتغير أو تتوقف؛ تحديثها يتطلب تحديث `channels.json`.
- لم يتم التحقق من تشغيل كل بث مباشر على جهاز التلفاز؛ نجاح البناء لا يضمن أن كل مصدر بث متاح دائماً.
